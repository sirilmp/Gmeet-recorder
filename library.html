Connect your Google Drive

One time, about 2 minutes. Uploads go into your Drive, and no Google Cloud setup is needed.
1Create a new script

Open script.google.com → New project with the Google account you want to upload to.

Then click Untitled project (top left) and name it Meet Recorder Drive Upload

2Paste the code

Click Copy, select everything in the editor (Ctrl+A), paste (Ctrl+V) and save (Ctrl+S).

3Give it permission

In the top bar choose authorize in the function list and click ▶ Run.

Click Review permissions → your account → Advanced → Go to Meet Recorder Drive Upload (unsafe) → Allow.

Google shows “unverified” only because it's your own private script.

4Publish it

Click Deploy → New deployment, then the ⚙ gear next to “Select type” → Web app.

Set Execute as: Me and Who has access: Anyone (work account: Anyone within your company), then click Deploy.

Changing the code later? Use Deploy → Manage deployments → ✏️ → New version.

5Paste the link here

Copy the Web app URL (ends with /exec), paste it below and press Connect & test.
